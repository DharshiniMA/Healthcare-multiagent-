# Healthcare Multi-Agent System

## Project Overview
Healthcare Multi-Agent System is an AI-powered healthcare assistant that uses multiple agents to process healthcare-related queries and provide intelligent responses.

## Features
- Multi-Agent Architecture
- Doctor Agent
- Orchestrator Agent
- Gemini AI Integration
- Web Interface
- Healthcare Database Support

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- SQLite
- Google Gemini API

## Installation

1. Clone the repository

git clone https://github.com/DharshiniMA/Healthcare-multiagent-.git

2. Install dependencies

pip install -r requirements.txt

3. Add Gemini API Key

Create a .env file:

GOOGLE_API_KEY=YOUR_API_KEY

4. Run the application

python main.py
